# Create Account UI (C# WinForms)

This is a simple beginner-friendly Create Account form built with C# and Windows Forms.

## Requirements
- Windows
- .NET 8 SDK
- Visual Studio 2022 or .NET CLI

## Run
```bash
dotnet build
```

Then open the generated `.exe` from the build output or run:

```bash
dotnet run
```

## Features
- Full name input
- Email input
- Password field
- Confirm password field
- Terms checkbox
- Success validation message
- Show/Hide password button

## Project structure
- `Program.cs` — app startup
- `CreateAccountForm.cs` — UI and validation logic
- `CreateAccountUI.csproj` — project config
